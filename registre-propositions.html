PROP-008 — Travail des prisonniers

Objet : Permettre aux détenus d'acheter une réduction de peine par le travail.

Obstacle constitutionnel documenté : Le Code criminel est de compétence fédérale. Le Québec ne peut modifier seul les peines. Trois voies identifiées :

  • Modification du Code criminel par le fédéral (hors portée)
  • Entente fédérale-provinciale (possible, précaire)
  • Recadrage en programme provincial de réinsertion (faisable immédiatement)

Recommandation : documenter l'obstacle ET prévoir une voie praticable à court terme.
