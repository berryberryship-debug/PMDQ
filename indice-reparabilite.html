Indice de Réparabilité Québécois (IRQ)

Moteur de transduction pour l'évaluation objective de la réparabilité — Version 2.7.5

1. Principe

L'IRQ est un outil de mesure qui transforme des caractéristiques physiques et juridiques d'un produit en un score unique sur 10. Il sert de base objective pour :

  • Classer les produits importés en grade 1 ou 2 (page Importations).
  • Appliquer la surtaxe prévue par le modèle MOD-ECO-CIRC-2025.
  • Vérifier la conformité à la Loi 29.

Base normative : EN 45554 (indice de réparabilité européen) et ISO 59000 (économie circulaire).

2. Les 5 critères (20 points chacun)

CritèreDescriptionScore max
1. OutillageStandard (20), propriétaire (5), destructif (0)20
2. DocumentationAccès gratuit et illimité (10 ans) : 20, sinon 020
3. Disponibilité spatio-temporellePièces garanties ≥ 7 ans et livrées ≤ 3 jours : 20. Intermédiaire : 10. Insuffisant : 520
4. Ratio économiquePièce ≤ 15 % du prix neuf : 20. Perte proportionnelle entre 15 % et 30 %. ≥ 30 % : 020
5. Intégrité logicielleAucun DRM matériel (appariement, sérialisation) : 20, sinon 020
TotalIndice final sur 10 (total / 10)100

2.1 Seuils de conformité

Indice IRQStatutConséquence
≥ 7,5 / 10CONFORMEAdmissible au label de durabilité (MOD-ECO-CIRC-2025).
< 7,5 / 10REJETÉSoumis à la surtaxe grade 1/2 prévue par le modèle.

3. Implémentation Python

Le moteur est implémenté en Python, avec une dataclass Produit et une classe EvaluateurMOD_ECO_CIRC.


import json
from dataclasses import dataclass, field
from typing import Dict

@dataclass
class Produit:
    nom: str
    fabricant: str
    # 'standard', 'proprietaire', ou 'destructif'
    type_outillage: str
    # Vrai si accès gratuit et illimité (10 ans)
    doc_ouverte: bool
    annees_garantie_pieces: float
    delai_livraison_jours: int
    # Ratio du coût de la pièce la plus chère sur le prix neuf
    ratio_prix_piece: float
    # Vrai si aucune sérialisation/DRM matériel n'entrave le remplacement
    sans_drm_materiel: bool

class EvaluateurMOD_ECO_CIRC:
    """
    Moteur de transduction pour l'Indice de Réparabilité Québécois (IRQ).
    Base normative : EN 45554 / ISO 59000.
    """
    def __init__(self):
        self.scores_max = 20.0

    def evaluer(self, produit: Produit) -> Dict[str, any]:
        scores = {}

        if produit.type_outillage == 'standard':
            scores['outillage'] = 20.0
        elif produit.type_outillage == 'proprietaire':
            scores['outillage'] = 5.0
        else:
            scores['outillage'] = 0.0

        scores['documentation'] = 20.0 if produit.doc_ouverte else 0.0

        if produit.annees_garantie_pieces >= 7 and produit.delai_livraison_jours <= 3:
            scores['disponibilite'] = 20.0
        elif produit.annees_garantie_pieces < 2 or produit.delai_livraison_jours > 14:
            scores['disponibilite'] = 5.0
        else:
            scores['disponibilite'] = 10.0

        if produit.ratio_prix_piece <= 0.15:
            scores['economie'] = 20.0
        elif produit.ratio_prix_piece >= 0.30:
            scores['economie'] = 0.0
        else:
            ratio_depassement = (produit.ratio_prix_piece - 0.15) / 0.15
            scores['economie'] = round(20.0 - (ratio_depassement * 20.0), 1)

        scores['integrite_logicielle'] = 20.0 if produit.sans_drm_materiel else 0.0

        total_100 = sum(scores.values())
        indice_10 = round(total_100 / 10.0, 1)

        return {
            "produit": produit.nom,
            "fabricant": produit.fabricant,
            "details_points": scores,
            "score_total_100": total_100,
            "indice_reparabilite_10": indice_10,
            "statut_approvisionnement": "CONFORME" if indice_10 >= 7.5 else "REJETÉ"
        }
