ModeleRatioD — Pydantic strict

from pydantic import BaseModel, ConfigDict, Field, field_validator
from math import isfinite
from typing import Literal


class ModeleRatioD(BaseModel):
    model_config = ConfigDict(
        strict=True, extra="forbid",
        allow_inf_nan=False, str_strip_whitespace=True
    )
    identifiant_projet: str = Field(..., min_length=1, max_length=100)
    axe_rattachement: str = Field(..., min_length=1, max_length=80)
    valeur_creee_nette: float = Field(..., gt=0)
    cout_cycle_vie: float = Field(..., gt=0)
    cout_risque: float = Field(..., ge=0)
    taux_actualisation: float = Field(..., ge=0.0, le=0.20)
    horizon_annees: int = Field(..., gt=0, le=100)
    categorie: Literal["M", "C", "P", "T"]

    @field_validator("valeur_creee_nette", "cout_cycle_vie",
                     "cout_risque", "taux_actualisation")
    @classmethod
    def verifier_valeur_finie(cls, valeur: float) -> float:
        if not isfinite(valeur):
            raise ValueError("NaN et infinis interdits.")
        return valeur

    @property
    def cout_total(self) -> float:
        return self.cout_cycle_vie + self.cout_risque

    def evaluer_ratio(self) -> float:
        return self.valeur_creee_nette / self.cout_total

    def statut(self) -> Literal["CONFORME", "REJETE"]:
        return "CONFORME" if self.evaluer_ratio() > 1.30 else "REJETE"

Annexe Technique : Résorption Thermodynamique des Îlots de Chaleur Urbains (ICU)

La valeur de climatisation passive calculée par le moteur Python n'est pas abstraite. Elle représente la conversion mathématique de la chaleur sensible en chaleur latente via l'évapotranspiration du système racinaire et de la canopée.

  • Capacité de dissipation : À pleine maturité, un tilleul transpire jusqu'à 400 litres d'eau par jour de canicule. Pour le réseau ciblé de 400 arbres, cela équivaut à un transfert thermique massif abaissant la température ambiante locale de 2 à 8°C dans les zones minéralisées.
  • Allègement du réseau d'État : Les kWh électriques évités modélisés dans l'audit démontrent une réduction de la pression sur le réseau énergétique lors des pointes estivales de climatisation.
  • Bouclier sanitaire : Le ciblage strict des quartiers est et des zones défavorisées convertit cette infrastructure biologique en bouclier contre la surmortalité liée aux extrêmes climatiques, justifiant structurellement le défraiement de 50 % de l'OPEX par les Villes.
