Moteurs de calcul

Scripts reproductibles du dossier PMDQ.

Statut : INFRASTRUCTURE — Quatre moteurs vérifient les agrégats, simulent les réformes et valident la cohérence du dossier. Tous sont exécutables localement (Python 3 ou Bash).

Vue d'ensemble

Résumé des moteurs de calcul du dossier PMDQ
Moteur Langage Rôle Sortie
Validation Ratio D Python (Pydantic) Vérifie que chaque projet respecte D > 1,30. Rejet / Acceptation
Audit robustesse Python Vérifie que les 36 pages répondent HTTP 200. CSV de verdicts
Comptable Gold Card Python Distingue cash encaissé, revenu reconnu et produit constaté d'avance. CSV des scénarios
Simulation réforme éducation Bash Modélise le pic transitoire primaire +16,6 %. CSV 12 ans

1. Validation Ratio D

Emplacement : Livre VII — Moteur Python

Langage : Python 3 + Pydantic (strict, anti-NaN/anti-infini)

Rôle : modélise chaque projet et vérifie que le ratio D = valeur créée nette / coût total est strictement supérieur à 1,30.

# Exemple — RESEAU-NARP-001
valeur_creee_nette : 1 850 000 000 $
cout_cycle_vie     :   980 000 000 $
cout_risque        :   180 000 000 $
cout_total         : 1 160 000 000 $

ratio D = 1 850 / 1 160 = 1,5948  >  1,30  ⇒  CONFORME

2. Audit robustesse

Emplacement : pmdq_audit.py (racine du dépôt)

Langage : Python 3

Rôle : vérifie que les 36 pages publiées répondent en HTTP 200.

$ python3 pmdq_audit.py

=== PMDQ — audit de robustesse ===
Total testé   : 36
Publiées OK   : 36
Dépôt intégralement cohérent.

3. Comptable Gold Card

Emplacement : gold-card-engine.py (racine du dépôt)

Langage : Python 3 (dataclasses, aucune dépendance externe)

Rôle : distingue — sur trois scénarios (pessimiste, central, optimiste) — le cash encaissé, le revenu reconnu en année 1, le produit constaté d'avance et le gain sur impayés.

$ python3 gold-card-engine.py

=== Scénario Central (10 grappes) ===
Cartes vendues          : 3,000
Cash encaissé (J0)      : 15,000,000 $
Revenu reconnu an 1     : 10,500,000 $
Produit constaté avance :  4,500,000 $
Gain impayés évités     :  1,500,000 $
Revenu éco. sécurisé    : 12,000,000 $

Détail complet : Fiche Gold Card

4. Simulation réforme éducation

Emplacement : reforme-education-demo.sh (racine du dépôt)

Langage : Bash (compatible Termux)

Rôle : modélise le pic transitoire de +16,6 % au primaire pendant 6 ans, puis la détransition sur 4 ans.

$ ./reforme-education-demo.sh

=== RÉFORME ÉDUCATION — SIMULATION DÉMOGRAPHIQUE v4 ===
