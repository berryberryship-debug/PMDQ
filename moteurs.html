1. Validation Ratio D

Emplacement : Livre VII — Moteur Python

Langage : Python 3 + Pydantic (strict, anti-NaN/anti-infini)

Rôle : modélise chaque projet et vérifie que le ratio D = valeur créée nette / coût total est strictement supérieur à 1,30.

# Exemple — RESEAU-NARP-001
valeur_creee_nette : 1 850 000 000 $
cout_cycle_vie     :   980 000 000 $
cout_risque        :   180 000 000 $
cout_total         : 1 160 000 000 $

ratio D = 1 850 / 1 160 = 1,5948  >  1,30  ⇒  CONFORME

13. Audit de publication — Détection Cialdini et traçabilité

Emplacement : moteur_audit_publication.py, audit_rules.py

Langage : Python 3 + Pydantic

Rôle : Analyse les textes publiés par la plateforme. Détecte les sept leviers de persuasion de Cialdini (réciprocité, rareté, autorité, cohérence, sympathie, preuve sociale, unité), vérifie que chaque affirmation factuelle ou économique porte une source vérifiable, et signale les risques de conformité DGEQ (appel à l'action sans autorisation, mention de dépense de tiers).

Sorties : chaque affirmation reçoit un statut — CONFORME, RÉVISION ou BLOCAGE. Le statut global (OK, A_REVISER, BLOQUE) détermine si le texte peut être publié.

Registre : chaque audit est archivé dans audit_registry.jsonl avec une empreinte SHA-256 du texte et du rapport, permettant une vérification postérieure.

Principe : aucune donnée factuelle n'est publiée sans source URL ou institutionnelle. Le moteur ne suggère pas de reformulation, il bloque la publication tant que la condition n'est pas remplie.
