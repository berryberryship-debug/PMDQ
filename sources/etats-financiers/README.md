# États financiers — Registre

## Statut
Dossier vide. Aucun état financier produit à ce jour.

## Objet
Ce dossier conservera les états financiers annuels du PMDQ, une fois le parti enregistré au DGEQ.

## Structure prévue

Chaque exercice financier produira 4 états :

| État | Description |
|---|---|
| **Bilan** | Actif, passif, actifs nets |
| **État des résultats** | Revenus, dépenses, excédent/déficit |
| **État de l'évolution des actifs nets** | Variation des actifs nets |
| **État des flux de trésorerie** | Activités d'exploitation, d'investissement, de financement |

## Échéancier (DGEQ)

- Période couverte : **1er janvier au 31 décembre**.
- Transmission au DGEQ : **avant le 30 avril** de l'année suivante.
- Vérificateur requis dès que les recettes dépassent **5 000 $**.
