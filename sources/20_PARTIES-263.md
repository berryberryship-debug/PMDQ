## Plan de renforcement continu (PRC)

Cycle MACSP en 5 phases :
M — Mesurer (collecte des indicateurs I1-I10, T1-T5, V1-V16)
A — Analyser (détection d'écarts, tendances)
C — Corriger (action corrective ciblée)
S — Standardiser (intégration dans les SOP)
P — Publier (publication en format ouvert)

## Les 8 axes de renforcement

AR1 Gouvernance : renforcer l'indépendance des comités (100 % avis conformes)
AR2 Budgétaire : réduire les écarts prévu/décaissé (écart moyen inférieur à 5 %)
AR3 Juridique : anticiper les incompatibilités (au moins 2 audits préventifs par an)
AR4 TI/Pydantic : renforcer l'anti-entropie (100 % rejet NaN/infini)
AR5 Autochtone : approfondir la consultation (au moins 2 rencontres par an)
AR6 Communication : améliorer la compréhension citoyenne (sondage supérieur à 70 %)
AR7 Audit : diversifier les auditeurs externes (au moins 3)
AR8 Sortie : préparer la dissolution (7/7 jalons complétés)

## Matrice de dépendances inter-invariants (10 x 10)

Les 10 invariants ne sont pas indépendants. Les chaînes critiques sont :

Chaîne A : I5 (scénarios A/B/C) -> I1 (déclenchement) -> I3 (47 articles)
Chaîne B : I6 (hypothèses) -> I1 (déclenchement) -> I7 (ventilation comptable)
Chaîne C : I1 (déclenchement) -> I7 (ventilation) -> I10 (conditions d'abandon)
Chaîne D : I3 (47 articles) -> I10 (conditions d'abandon)

Si I1 casse : I3, I7 et I10 sont menacés.
Si I7 casse : I10 est menacé.
Si I5 casse : I1 et I3 sont menacés.
