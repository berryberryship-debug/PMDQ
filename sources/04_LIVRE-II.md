## §2 — Règle de déclenchement et 6 encadrés normatifs

### Encadré 1 — Ratio de Rendement Collectif D

D = V_créée_nette(H,r) / Somme_{t=0}^{H} [ (C_cycle_vie,t + C_risque,t) / (1+r)^t ]

Condition exécutoire : D supérieur à 1,30.

### Encadré 2 — Ressource globale

R_globale_t = R_t + Ré_t + É_t + Co_t

### Encadré 3 — Ressource admissible

R_admissible_t = R_t + Ré_t + É_t

Les revenus conditionnels Co_t sont strictement exclus.

### Encadré 4 — Règle de décaissement

Delta_net_t = min( Pi_t , R_admissible_t + Report_{t-1} - Réserve_t )

### Encadré 5 — Réserve préventive (15 %)

Réserve_t = 0,15 x ( R_admissible_t + Report_{t-1} ) pour t dans 1, 2, 3
Réserve_4 = 0

### Encadré 6 — Équation de Domar

s* = [(i - g) / (1 + g)] x d
