# Contributions — Registre

## Statut
Dossier vide. Aucune contribution reçue à ce jour.

## Objet
Ce dossier conservera les reçus et la liste des contributions reçues par le PMDQ, conformément aux règles du DGEQ.

## Structure prévue

Chaque contribution sera consignée dans un fichier CSV avec les colonnes suivantes :

| Colonne | Description |
|---|---|
| `date_reception` | Date de réception (AAAA-MM-JJ) |
| `nom_donateur` | Nom complet |
| `adresse` | Adresse municipale |
| `code_postal` | Code postal |
| `montant` | Montant en CAD |
| `mode` | Chèque / carte / transfert |
| `recu_emis` | Oui / Non |
| `transmis_dgeq` | Oui / Non (obligatoire pour 100 $ et plus) |

## Règles applicables (DGEQ)

- Plafond : **100 $ par année** par électeur, **+100 $** l'année d'une élection générale ou partielle.
- Contributions supérieures à **50 $** : chèque ou carte de crédit uniquement (aucun argent comptant).
- Contributions supérieures à **100 $** : transmission obligatoire au DGEQ.
- Aucune personne morale (compagnie, organisme) ne peut contribuer.

## Fichiers

- `contributions.csv` — à créer dès la première contribution.
