Faire de la politique pour créer de la richesse.

Le PMDQ n'est pas un programme de promesses. C'est un dossier de 74 pages où chaque chiffre a sa source, chaque correction est publiée, et chaque engagement peut être contesté.

Entrez dans le dossier

Notre ligne

La politique n'est pas un spectacle. C'est un outil.

L'État québécois doit faire trois choses, et rien d'autre :

  • Financer l'innovation. Ce qui est désuet se remplace. Ce qui est neuf se teste. Ce qui marche s'industrialise.
  • Créer de la richesse, pas seulement la redistribuer. Les questions d'affaires et les questions politiques ne se séparent pas. Une économie qui produit localement vaut mieux qu'une économie qui consomme importé.
  • Empêcher les catastrophes. Financières, écologiques, technologiques. La dette se mesure, le climat se prépare, la dépendance se réduit. La science est notre boussole — pas les slogans.

Nos énoncés politiques sont stabilisés par la plateforme. Chaque chiffre est tracé, chaque affirmation est comparable, chaque correction est publique. Un énoncé politique qui n'est pas stabilisé ne tient pas dans le temps. Le nôtre, si.

Les trois engagements

Voir clair
L'État rend ses décisions compréhensibles. Chaque dollar est traçable. Chaque chiffre a sa source.
Produire ici
L'énergie, les données, les ressources servent d'abord la capacité du Québec à se loger, se nourrir, se soigner, innover.
Protéger demain
Réduire les vulnérabilités : dette, dépendance, logement, chaînes d'approvisionnement. La résilience n'est pas la peur, c'est la préparation.

Ce qu'on propose

FQBC — 8,4 G$ sur 4 ans — Investir sans déficit. Chaque dollar sorti doit être encaissé et vérifié.
Logement modulaire — Construction accélérée, taxe sur la vacance spéculative.
Éducation — 7ᵉ année primaire, méthode syllabique explicite.
Santé — Accès RAMQ prioritaire inconditionnel. Pilote réversible pour capacités résiduelles.
Mobilité légère — Véhicule urbain biplace assemblé au Québec.
Ressources critiques — Transformation locale obligatoire du lithium et du graphite.

Chaque promesse est liée à un projet chiffré. Formule, source, condition d'arrêt — tout est public.

Comment on le fait

  • Traçabilité — Chaque chiffre porte un marqueur : [M] mesuré, [C] calculé, [P] prospectif, [T] établi.
  • Audit public — 20/20 intégrité. 76/76 robustesse. Mis à jour à chaque commit.
  • Correction ouverte — Quand un chiffre change, c'est documenté dans le changelog public.
  • 12 moteurs de calcul — Dette, fiscalité, provisionnement, mobilité, santé. Chaque moteur est un code Python vérifiable.
