Livre IV — Simulateur budgétaire

Règle de déclenchement, réserve préventive, exécution sur 4 exercices.

Règle de déclenchement exécutoire

Décaissements autorisés_t ≤ Ressources encaissées_t
                          + Crédits légalement votés_t
                          + Report_{t-1}
                          − Réserve exigée_t

Réserve préventive (15 %)

Réserve_t = 0,15 × ( R_admissible_t + Report_{t-1} )
Réserve_4 = 0   (libération à l'exercice final)

Détail des calculs

Année 1

  • Assiette : 2,100 + 0,000 = 2,100 G$
  • Réserve exigée : 0,15 × 2,100 = 0,315 G$
  • Plafond net : 2,100 − 0,315 = 1,785 G$
  • Décaissé : min(1,600 ; 1,785) = 1,600 G$
  • Report sortant : 0,185 G$

Année 2

  • Assiette : 2,100 + 0,185 = 2,285 G$
  • Réserve exigée : 0,15 × 2,285 = 0,343 G$
  • Plafond net : 1,942 G$
  • Décaissé : min(2,400 ; 1,942) = 1,942 G$
  • Suspension : 0,458 G$

Année 3

  • Assiette : 2,100 G$
  • Réserve exigée : 0,315 G$
  • Plafond net : 1,785 G$
  • Décaissé : min(2,600 ; 1,785) = 1,785 G$
  • Suspension : 0,815 G$

Année 4 (libération)

  • Assiette : 2,100 G$
  • Réserve exigée : 0 (dernière année)
  • Plafond net : 2,100 G$
  • Décaissé : min(1,800 ; 2,100) = 1,800 G$
  • Report sortant : 0,300 G$ (reliquat final)

Lecture de l'exécution

  • An 1 : exécution pleine (1,600 G$).
  • An 2 : suspension partielle de 0,458 G$ (plafond net insuffisant).
  • An 3 : suspension de 0,815 G$ (plafond net insuffisant).
  • An 4 : libération de la réserve, exécution pleine, reliquat de 0,300 G$.

Interprétation stratégique

Le FQBC ne peut pas dépenser 8,40 G$ en 4 ans. Il en dépense 7,127 G$. La différence (1,273 G$) comprend :

  • 0,973 G$ de réserve préventive non consommée, libérée à l'exercice 4
  • 0,300 G$ de reliquat final, reversé au Fonds consolidé pour désendettement

Convention d'arrondi

Deux modes possibles

Mode documentaire (retenu) : réserve arrondie à 0,001 G$ avant calcul du plafond. Résultat : 7,127 G$ décaissé.

Mode normatif exact : calcul sans arrondi intermédiaire. Résultat légèrement différent.

Le mode documentaire permet la reproduction exacte des chiffres publiés.
