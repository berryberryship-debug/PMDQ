Analyse externe du PMDQ

Synthèse critique du Dossier Maître v2.7.5 + Livre X — Version corrigée

Note : cette analyse est une synthèse externe du dossier. Elle ne constitue pas un engagement du PMDQ et les chiffres cités sont vérifiables dans les pages sources.

1. Vision générale et positionnement

  • Slogan : « PMDQ — Un État qui livre » / « Voir clair ».
  • Philosophie : réduire l'écart entre les annonces, les budgets et les résultats. Approche « scientifique de terrain », transparence budgétaire, soutenabilité mathématique.
  • Cible : classe moyenne, production locale, transition énergétique pragmatique.

3. Propositions phares

  • Refonte scolaire : 7e année primaire + transfert de l'année préparatoire au baccalauréat aux universités.
  • Régulation financière : 6 encadrés normatifs interdisant les déficits structurels non adossés à des gains de productivité mesurables.
  • Transparence algorithmique : code Python open source.

4. Statut actuel

  • Phase : lancement et phase préparatoire.
  • Objectif organisationnel : constitution d'une équipe fondatrice pour la validation externe et la préparation législative.

6. Note méthodologique sur les chiffres

Les chiffres cités proviennent des pages sources du dossier :

  • FQBC 8,4 G$ — notation française (8,400 G$), soit 8,4 milliards de dollars. Le total des trois scénarios (A, B, C) est cohérent : 5,14 + 2,57 + 0,69 = 8,40 G$.
  • Économies 2,57 G$ — scénario B (Central).
  • Domar 2,23 à 5,29 G$/an — effort d'équilibre primaire.
